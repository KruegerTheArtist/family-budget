# Семейный бюджет — PWA

Устанавливаемое офлайн-приложение для учёта доходов и расходов. Код публичный,
**личные данные в репозитории не хранятся** — они живут только на твоём устройстве
(постоянное хранилище установленного приложения) и в твоём файле-бэкапе.

Онлайн: **https://kruegertheartist.github.io/family-budget/**

## Что внутри
- `index.html` — приложение (логика, стили, стартовая структура категорий; без личных данных).
- `manifest.webmanifest` — описание PWA.
- `service-worker.js` — офлайн-кэш (после первой загрузки открывается без интернета).
- `icon-*.png` — иконки.

## Первый запуск (один раз)
1. Открой ссылку на телефоне → добавь на главный экран:
   - **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
   - **Android (Chrome):** меню ⋮ → «Установить приложение».
2. Запусти с иконки. Приложение попросит разрешение на постоянное хранилище — разреши.
3. Загрузи свои данные: **Данные → Восстановить из бэкапа → Выбрать файл .json**
   (файл `family-budget-data.json` — закинь его на телефон, например через «Избранное» в Telegram).

Дальше данные хранятся на устройстве постоянно — импорт больше не нужен.

## Бэкап
- **Данные → Сделать бэкап (файл)** — скачивает `.json` с текущими данными. Делай периодически.
- Восстановление / перенос на другой телефон — тем же файлом через «Восстановить из бэкапа».

## Как это обновлять на GitHub
Репозиторий: `kruegertheartist/family-budget`, ветка `main`, GitHub Pages из `main` / `root`.
После изменения файлов:
```bash
git add .
git commit -m "update"
git push
```
Если менял код — подними версию кэша в `service-worker.js` (`budget-v1` → `budget-v2`),
иначе телефон может показать старую закэшированную версию.

## Синхронизация с Google-таблицей (необязательно)
Можно подключить свою Google-таблицу как облачное хранилище: данные будут
синхронизироваться между устройствами и жить в таблице (её можно открывать и
редактировать руками). Бэкенд — Google Apps Script (файл `google-apps-script.gs`).

Настройка (разово, ~10 мин):
1. Создай Google-таблицу → **Расширения → Apps Script**.
2. Вставь код из `google-apps-script.gs`, замени `SECRET` на свой токен.
3. **Deploy → New deployment → Web app**: Execute as **Me**, Who has access **Anyone** → Deploy → Authorize.
4. Скопируй **Web app URL** (…/exec).
5. В приложении: **Данные → Синхронизация → Подключить таблицу** → вставь URL и тот же токен →
   «Проверить подключение» → «Сохранить» → согласись отправить текущие данные в таблицу.

Как работает: приложение подтягивает данные из таблицы при открытии и отправляет изменения
(при включённой автосинхронизации — автоматически). Если данные менялись и там, и там —
покажет «конфликт» с выбором, что оставить. Токен хранится только на устройстве и **не**
попадает в публичный репозиторий.

## Важно про хранение
- GitHub Pages — хостинг только для чтения: приложение **не может** писать данные обратно в репозиторий.
- Без Google-синхронизации данные хранятся на устройстве (надёжно, в постоянном хранилище PWA), а файл-бэкап — твоя страховка.
- С Google-синхронизацией источник правды — таблица; локальное хранилище работает как офлайн-кэш.
